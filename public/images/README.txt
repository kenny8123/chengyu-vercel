圖片放置說明（合併版：1-1 + 2-1 + 3-1）
========================
全部圖片放在同一個 public/images/ 資料夾內，不需要分子資料夾。
只有「典故閱讀」頁面會顯示圖片，練習與評級測驗階段是純文字模式。

【1-1 單元】
1.png             = 1-1 序章圖
s1.png ~ s10.png  = 1-1 十個典故的學習漫畫

對應：s1=一言九鼎 s2=寸草春暉 s3=人山人海 s4=水落石出 s5=青出於藍
     s6=滄海桑田 s7=守口如瓶 s8=分道揚鑣 s9=手足無措 s10=刮目相看

【2-1 單元】檔名含空格，請完整複製：
「2-1 0.png」          = 2-1 序章圖
「2-1 1.png」～「2-1 10.png」  = 2-1 十個典故的學習漫畫

對應：1=千方百計 2=始作俑者 3=白頭偕老 4=借刀殺人 5=賞心悅目
     6=日新月異 7=緣木求魚 8=赴湯蹈火 9=初來乍到 10=弱肉強食

【3-1 單元（新）】檔名用連字號，格式如「上冊-下冊-題號」：
「3-1-0.png」          = 3-1 序章圖（可省略，沒有會自動顯示emoji）
「3-1-1.png」～「3-1-10.png」  = 3-1 十個典故的學習漫畫

對應：1=禮尚往來 2=爭先恐後 3=立竿見影 4=吳牛喘月 5=異曲同工
     6=格殺勿論 7=半斤八兩 8=少見多怪 9=包羅萬象 10=莫逆之交

【未來擴充】
之後的單元（4-1、5-1...）都比照 3-1 的命名規則：
「X-1-0.png」序章圖、「X-1-1.png」~「X-1-10.png」學習圖
