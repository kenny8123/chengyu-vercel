# 成語穿越者（一頁式 + 挑戰系統大改版）

## 本次六大改動

### 1. 一頁式首頁
序章、選單元、成語清單三個畫面合併成一頁：
標題「成語穿越者」+ 序圖 + 說明 + 單元一～四手風琴摺疊清單。
點單元標題展開/收合，不用跳頁；點成語直接進典故+練習頁。

### 2. 不洩題
練習作答畫面不再顯示成語名稱，改用「第X題・第X階段」命名。

### 3. 拖字區加大間距
答題空格區與字盤拖曳區之間加上分隔線與明顯間距，
字盤區加上淺色卡片背景，視覺上更像一般拼字遊戲。

### 4. 移除「第幾字」提示
空格上不再顯示「第一字」「第四字」等提示標籤。

### 5. 挑戰系統只顯示最佳成績
選模式卡片直接顯示「🏆 最佳成績：XX 分」，不摺疊、不顯示歷史列表。

### 6. 挑戰系統大改（原「評級系統」改名「挑戰系統」）
新增兩個模式，取代舊的「選單元→固定40題」邏輯：
- **模式A・自由選題**：選一個單元（單元一～四），
  從該單元的4個階段題庫中隨機抽10題（每題隨機分配到某一階段）
- **模式B・隨機40題**：橫跨全部4個單元、全部4個階段的總題庫，
  隨機抽40題進行綜合測驗
- 兩種模式的成績、錯題記錄各自獨立存檔（歷史最高分分開計算）

## Bug 修正：慶祝彩帶把手機版面撐長
burst() 會建立 class="confetti" 的 div 並設定 left / fontSize / animationDuration，
但 globals.css 從來沒有 .confetti 這個規則，所以那些 div 變成一般區塊元素，
堆在 <body> 最後、沿左側直排，並把頁面高度撐出一大片空白（手機上特別明顯）。
已補上 .confetti（position:fixed + confettiFall 飄落動畫 + pointer-events:none），
並把 left 的隨機範圍從 0~100vw 收成 4~92vw，避免掉在畫面外。
另外加上 prefers-reduced-motion 時不顯示。

## 挑戰系統改版：自由選階段 + AI對決

### 模式A「自由選題」
流程改為 選單元 → **選階段** → 該單元 10 個成語全部用同一階段出題（順序打亂）。
原本是系統每題隨機配階段，學生不能選；現在階段由學生決定。
- buildFreeQuizQueue(unitKey, round) 改為吃指定 round
- 新增畫面 'rank-mode-a-round'，四張卡對應四個階段，說明文字在 ROUND_DESC

### 模式B 改為「⚔️ AI對決」
橫跨全部單元 40 題，與 AI 對手「鼎鼎」搶答。
- **計分**：同題競速，誰先答對誰得分；被搶走就換下一題
- **限時**：每題 20 秒（BATTLE_SECONDS），上方有倒數條，剩 5 秒轉紅閃爍
- **超時**：算學生答錯，自動跳下一題
- **AI 行為模型**（AI_PROFILE / rollAiTurn）：模擬國中生，階段越難想越久、越容易錯
    第一階段 4~9 秒、正確率 90%
    第二階段 6~12 秒、正確率 82%
    第三階段 8~15 秒、正確率 72%
    第四階段 9~17 秒、正確率 62%
  要調難度改 AI_PROFILE 即可（acc 調低 = AI 變弱）
- **單題流程**：AI 到時間出手 → 答對就搶分、答錯則讓出機會；
  學生答錯視同出局，若 AI 也已答錯則本題無人得分
- **結算畫面 'battle-result'**：雙方比分與勝負、四種結果次數
  （搶答成功／被搶先／自己答錯／時間到），各階段搶分率，
  最弱階段提醒，以及沒搶到的成語清單（點擊回去複習典故）
- 成績以 key 'ai-battle' 存入歷史記錄，模式卡會顯示最佳成績

## AI對決固定為第四階段
挑戰模式定位是最高難度，40 題全部使用第四階段（整句挖空＋干擾字），
由常數 BATTLE_ROUND 控制，要改難度改這個值即可。
連帶調整：
- 結算移除「各階段搶分率」與最弱階段提示（只有單一階段，沒有比較意義），
  改為一行說明挑戰模式的難度設定
- 錯題卡片不再標階段，改顯示「待複習」
- AI 對手因此一律套用第四階段的行為模型：9~17 秒出手、正確率 62%
