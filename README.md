# 成語驗驗看（動線優化版）

## 側邊欄
- 📖 學習與練習
- 📝 評級系統

## 動線一：學習與練習
選單元（1-1 / 2-1，附簡短單元說明）→ 成語清單
→ 點一個成語 → 看典故（漫畫+故事+原文）
   → 「✏️ 開始練習這個成語」一鍵按鈕
   → 自動依序跑完四輪（挖1字→挖2字→全字挖空→全字挑戰），
     每輪答對才進下一輪，答錯可重來，不用手動選模式
   → 四輪跑完自動回到典故頁

## 動線二：評級系統
選單元 → 說明 → 學習10典故 → 四輪盲測（每題1次機會，共40題）
→ 診斷報告（總分、四輪明細、易錯成語、ABC評級）
  → ⭐ 推薦優先加強的輪次（依表現最弱的一輪自動推薦）
  → 或自己選擇任一輪次 → 選成語 → 該輪次單獨練習（可重試、可重複）
