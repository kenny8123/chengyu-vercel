# 成語驗驗看 1-1

## 流程
序章 → 地圖（成語驗驗看 1-1 / 自由練習）

### 成語驗驗看 1-1（正式評級流程）
說明 → 學習10典故（原文直接展開）
  → 四輪評級測驗（每題1次機會，不能重試，共40題）
     1. 挖1字＋輕度干擾
     2. 挖2字＋輕度干擾（更多）
     3. 全字挖空，無干擾
     4. 全字挖空＋高辨識度干擾（形近/音近字）
  → 診斷報告（四輪明細＋易錯成語＋總評級ABC）
  → 第二關：說明評級依據 → 推薦優先練習的輪次 → 導向自由練習

### 自由練習（不限流程，隨時可用）
選任一成語 → 選模式（學習/挖1字/挖2字/全空/全空挑戰）
→ 可重複練習、隨時換題目或模式，答錯可重試

滄海桑田、守口如瓶、分道揚鑣、手足無措、刮目相看

## 評分邏輯
四輪權重：第1輪5分/題、第2輪8分/題、第3輪10分/題、第4輪12分/題
滿分(5+8+10+12)×10=350，換算為100分制
80分以上=A級，40~79分=B級，40分以下=C級
系統會標出四輪中表現最弱的一輪，並列出最常答錯的成語
