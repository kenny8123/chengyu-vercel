# 成語穿越者（一頁式 + 評鑒系統大改版）

## 本次六大改動

### 1. 一頁式首頁
序章、選單元、成語清單三個畫面合併成一頁：
標題「時空穿越者」+ 序圖 + 說明 + 單元一～四手風琴摺疊清單。
點單元標題展開/收合，不用跳頁；點成語直接進典故+練習頁。

### 2. 不洩題
練習作答畫面不再顯示成語名稱，改用「第X題・第X階段」命名。

### 3. 拖字區加大間距
答題空格區與字盤拖曳區之間加上分隔線與明顯間距，
字盤區加上淺色卡片背景，視覺上更像一般拼字遊戲。

### 4. 移除「第幾字」提示
空格上不再顯示「第一字」「第四字」等提示標籤。

### 5. 評鑒系統只顯示最佳成績
選模式卡片直接顯示「🏆 最佳成績：XX 分」，不摺疊、不顯示歷史列表。

### 6. 評鑒系統大改（原「評級系統」改名「評鑒系統」）
新增兩個模式，取代舊的「選單元→固定40題」邏輯：
- **模式A・自由選題**：選一個單元（單元一～四），
  從該單元的4個階段題庫中隨機抽10題（每題隨機分配到某一階段）
- **模式B・隨機40題**：橫跨全部4個單元、全部4個階段的總題庫，
  隨機抽40題進行綜合測驗
- 兩種模式的成績、錯題記錄各自獨立存檔（歷史最高分分開計算）

## Bug 修正：評鑒測驗做完卡住不跳成績頁
原因：先前重構移除了 viewingUnit state，但 checkQuizAnswer 最後一題的分支
仍呼叫 setViewingUnit(key)，setTimeout 內拋出 ReferenceError，
導致 setScreen('rank-diagnosis') 沒被執行，畫面停在最後一題。
已移除該行呼叫。

## 成績頁強化
- 新增「你在第X階段錯得最多」的提示句（正確率最低且非全對的階段）
- 錯題卡片：只錯一次時顯示「第X階段答錯」，錯多次才顯示「答錯 N 次」
- 歷史記錄一併存入 totalQuestions 與 weakestRound
- 側邊欄「評級測驗進行中」統一改為「評鑒測驗進行中」

## 練習模式結算：加入評語與階段分析
- 新增 practiceMistakes state，記錄本輪練習中四個階段各答錯幾次
  （開始練習、回看典故、換成語、從錯題複習進入時都會歸零）
- 完成畫面新增：
  1. 評語：依總錯誤次數分四級（0 次🏆完美 / 1-2 次🌟很好 / 3-5 次💪加油 / 6 次以上📖再練一次）
  2. 四階段明細：各階段「一次答對」或「答錯 N 次」，加上總計
  3. 「你在第X階段錯得最多」提示（同分時取較後面、難度較高的階段）
- 評語邏輯在 summarisePractice() 函式，要調整級距或文案改那裡即可

## 練習模式：自動判定 + 精簡按鈕
- 空格全部填滿後 380ms 自動送出判定，不需再按「拼好了」
  （實作在 canCheckPractice 後方的 useEffect；要調整延遲改 380 那個數字）
- 移除「✅ 拼好了」按鈕，保留「🔄 重來」；答對後仍出現「下一階段 →」
- 答錯時原本就會清掉放錯的字並重置 result，因此不會觸發無限重判
- 練習完成畫面只保留「📜 回看典故」一個按鈕（改為主要按鈕樣式 btn-go）

## 評鑒測驗：同樣改為自動判定
- 空格填滿後 700ms 自動送出（比練習的 380ms 長，因為每題只有一次機會，
  留時間讓使用者點空格把字拿回來重放）
- 移除「✅ 提交答案」按鈕與該區塊
- 換題由 initQuizQ 重置 placed，不會在新題目一進來就誤判
