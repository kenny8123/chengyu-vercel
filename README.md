# 成語穿越者（評測直達 + 歷史成績功能）

## 本次修改
1. **移除評測前的閱讀典故步驟**：選單元後直接開始四階段盲測測驗，
   不用先讀完10個典故才能測
2. **診斷報告加回答錯次數**：答錯的成語卡片會顯示「答錯 X 次」
3. **新增歷史成績功能**（使用 localStorage，存在使用者裝置本機）：
   - 每次完成測驗自動記錄（最多保留每單元20筆）
   - 選單元卡片上顯示「上次成績：XX 分」
   - 有測驗記錄的單元會出現「📊 歷史成績」按鈕，可查看完整歷史列表
   - 點任一筆歷史記錄可看到那次的答錯成語，點下去直接複習
   - 診斷報告畫面也可以直接「查看歷史成績」

## 注意事項
歷史成績存在瀏覽器 localStorage，僅該裝置、該瀏覽器保留，
換裝置、換瀏覽器或清除瀏覽器資料會遺失記錄，非跨裝置雲端同步。

## 側邊欄
- 📖 學習與練習
- 📝 評級系統
- 🤖 導覽機器人「鼎鼎」（右下角）
- Aa 文字大小調整（左上角）

## 動線一：學習與練習
選單元 → 成語清單 → 點成語看典故 → 「開始練習」→ 自動跑四階段

## 動線二：評級系統
選單元 → **直接開始四階段盲測**（鎖側邊欄）
→ 成績（分數 + 答錯題目及次數，點下去複習）
→ 可查看歷史成績列表
