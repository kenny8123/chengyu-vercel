# 成語驗驗看（練習去圖化 + 動線再簡化版）

## 本次四項修改
1. **練習頁不顯示圖片**：Scene 元件改為純文字版，只在「典故閱讀」頁保留圖片
2. **一鍵四輪練習跑完不自動跳轉**：完成後留在原地顯示「四輪完成」畫面，
   學生自己決定回看典故／再練一次／換成語
3. **診斷報告簡化**：移除「推薦輪次」和「四顆自選輪次」按鈕，
   移除「回去加強練習」「挑戰其他單元」兩顆按鈕；
   改為列出「答錯較多的成語」（最多5個），點下去直接進入該成語的典故閱讀頁
4. **評級測驗進行中鎖側邊欄**：學習典故(rank-learn)和四輪盲測(rank-drill)期間，
   側邊欄只留「返回首頁」，隱藏「學習與練習」「評級系統」入口，
   避免學生中途切換模式放棄測驗

## 側邊欄
- 📖 學習與練習
- 📝 評級系統
（評級測驗進行中兩者暫時隱藏）

## 動線一：學習與練習
選單元 → 成語清單 → 點成語看典故（含圖片）
→「開始練習」一鍵按鈕 → 自動跑四輪（純文字練習，無圖）
→ 完成後留在原地，學生自選下一步

## 動線二：評級系統
選單元 → 說明 → 學習10典故（含圖片）→ 四輪盲測（純文字，共40題，鎖側邊欄）
→ 診斷報告（總分、四輪明細、強弱項、錯題列表）
→ 點錯題直接跳典故閱讀頁複習
